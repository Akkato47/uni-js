# Задание 2 — TodoList

Открыть index.html в браузере. Плюс открывает форму, галочка сохраняет, стрелка отменяет. У записи есть выполнение, редактирование и удаление. После перезагрузки задачи сохраняются.

Массив tasks содержит объекты id, text, done. openModal и closeModal переключают экраны. createTask добавляет задачу или сохраняет редактирование, deleteItem удаляет по id, setDone меняет done, renderTodoList создаёт элементы списка. Текст вставляется через textContent.

localStorage хранит массив как JSON: getItem читает, setItem сохраняет, removeItem удаляет ключ после удаления последней задачи. Для демонстрации остальных возможностей открыть консоль браузера: storageInfo() показывает length и ключи через key(index), clearStorage() вызывает clear() после подтверждения. clear() очищает всё хранилище текущего адреса.

Для защиты: создать две записи, отметить и снять выполнение, отредактировать, отменить редактирование, обновить страницу и удалить записи. Пустая запись не сохраняется.
