# Задание 3 — Конвертер валют

Открыть index.html. Нажатие на сумму выбирает активное поле (зелёное). Клавиатура вводит цифры и запятую, AC очищает, ⌫ удаляет последний символ. Нажатие на название валюты открывает список. Поиск работает по коду и названию через filter(), на событиях input и change. Галочки отмечают обе выбранные валюты.

Можно ввести максимум два знака после запятой. Последующие цифры игнорируются и не участвуют в расчёте. Результат округляется до двух знаков, курсы используются с исходной точностью. Переключение поля не меняет исходную сумму: обратный расчёт начинается только после её изменения.

В data.js учебные фиксированные курсы, это не текущие котировки. Приложение работает без интернета. Value — стоимость Nominal единиц в рублях. Формула: сумма × (Value исходной / Nominal исходной) / (Value целевой / Nominal целевой). Рубль добавлен через push().

Проверка для защиты: 100 USD = 9261 RUB; 100 JPY = 61,5 RUB; одинаковые валюты дают одинаковые суммы. Показать обратный пересчёт, дробный ввод, AC, удаление цифры и поиск «доллар» / «USD».
